# File map

- `CLAUDE.md` — agent rules and commands
- `docs/SPEC.md` — goals, architecture, flag scheme, full challenge catalogue
- `docs/PLAN.md` — ordered tasks and status
- `CMakeLists.txt` — top-level ESP-IDF project (esp32_ctf)
- `sdkconfig.defaults` — target/flash/partition/console/Bluedroid dual-mode/coex defaults; Wi-Fi IRAM opts off (IRAM headroom)
- `partitions.csv` — 4 MB layout: nvs, phy_init, factory 2560K, notes, storage (SPIFFS)
- `dependencies.lock` — managed component lock (espressif/mdns)
- `main/` — boot sequence
- `main/main.c` — app_main: platform init, SER-01 boot banner, always-on + mode tracks, console start; optional size-probe stubs
- `main/Kconfig.projbuild` — `CONFIG_CTF_SIZE_PROBE` (dev only, default n)
- `main/idf_component.yml` — managed deps (espressif/mdns)
- `components/ctf_core/` — portable flag/registry/scoring engine (no IDF headers, no heap)
- `components/ctf_core/include/ctf_core.h` — public API: catalogue, flags, derive, submit, answer gates, hints, score, backend
- `components/ctf_core/include/ctf_sha256.h` — SHA-256 / HMAC-SHA256 API (usable by tracks, e.g. JWT)
- `components/ctf_core/ctf_core.c` — engine state, XOR-split key, derivation, submission, tagged progress record
- `components/ctf_core/ctf_catalog.c` — static 40-challenge catalogue (SPEC order = progress bit index) + hints
- `components/ctf_core/ctf_sha256.c` — portable SHA-256 + HMAC-SHA256 implementation
- `components/ctf_platform/` — IDF glue: NVS, MAC, mode, console
- `components/ctf_platform/include/ctf_platform.h` — public API: init, MAC, mode get/set+reboot, console byte hook, console start
- `components/ctf_platform/ctf_platform.c` — NVS init + ctf_core backend (ctf/progress), mutex, MAC, mode (ctf/mode), esp_console init
- `components/ctf_platform/ctf_console.c` — UART0 line editor task (raw-byte hook, echo, backspace, `ctf> ` prompt) → esp_console_run
- `components/ctf_platform/ctf_commands.c` — core commands: status, list, submit, answer, hint, mode, reset
- `components/ctf_platform/ctf_platform_priv.h` — internal: ctf_commands_register
- `components/track_*/` — one component per challenge track; `track_<name>_start()` called from app_main
- `test/host/` — host build + unit tests for ctf_core
- `test/host/CMakeLists.txt` — builds components/ctf_core/*.c + test_*.c, registers with ctest
- `test/host/test_util.h` — CHECK/RUN macros, in-memory backend, test group declarations
- `test/host/test_main.c` — runner `main`, in-memory backend with lock-nesting tracking, test MACs
- `test/host/test_crypto.c` — SHA-256 vectors, RFC 4231 HMAC cases 1-4, 6, 7
- `test/host/test_catalog.c` — catalogue vs SPEC (IDs, names, levels, kit), points, max score
- `test/host/test_flags.c` — flag format/determinism/MAC sensitivity, derive, submit normalisation, answer gates
- `test/host/test_progress.c` — hint cost + score, persistence, tampered record, reset, no backend
- `components/track_serial/` — SER-02..04 (UART2 beacon, timing login, escape hook) + CRY-01 shard 1
- `components/track_crypto/` — CRY-01..03 console commands (`cipher`, `oracle`, `msgs`); Kconfig `CONFIG_CTF_CRYPTO_DEV`
- `solvers/serial/` — SER solvers + `_util.py` console helpers (pyserial)
- `solvers/crypto/` — CRY solvers
- `components/track_re/` — RE-01..04 boot-time provisioning (notes partition, NVS vault k/chk, SPIFFS blob.bin) + `unlock` command; mounts SPIFFS
- `solvers/re/` — RE solvers (esptool dump + nvs_tool.py), `_util.py`, README with Ghidra loading guide
- `components/track_hw/` — HW-01..06 (jumper check, Morse LED, LEDC PWM, bit-banged I2C/SPI, touch keypad), `keypad` cmd; Kconfig `CONFIG_CTF_HW_DEV` (`hwdev` cmd)
- `solvers/hw/` — HW solvers/decoders, `_util.py`, README with manual kit steps
- `components/track_ble/` — BT bring-up (BTDM + Bluedroid), advertising/BLE-07 rotation, GATT challenge + CTF control services, BLE-01..11, CRY-01 shard 2, `ble` cmd; `track_ble_bt_ready()`
- `solvers/ble/` — bleak solvers ble01..ble11, `_util.py`, README.md (GATT table, UUIDs)
- `components/track_btc/` — BTC-01..03: SPP console + shell, BR/EDR name/CoD/EIR, CRY-01 shard 3
- `solvers/btc/` — BTC solvers (D-Bus inquiry, SDP/RFCOMM), `_util.py`, README (BTC-03 encoding; needs /usr/bin/python3 for AF_BLUETOOTH)
- `components/track_web/` — WEB-01..09, /score, /submit, CRY-01 shard 4, `wifi` cmd; Kconfig `CONFIG_CTF_WEB_DEV_STA*` (dev LAN testing)
- `components/track_web/web_http.c` — port-80 handlers, JWT, /diag confinement, WS, /score, /submit
- `components/track_web/web_net.c` — WEB-08 mDNS beacon, WEB-09 knock/door
- `components/track_web/www/` — embedded page templates + robots.txt
- `solvers/web/` — web solvers (`--host`), `_util.py` (DTR/RTS-safe serial open), README
- `sdkconfig.dev.local` — (git-ignored, user-created) dev STA Wi-Fi credentials overlay
- `solvers/common/console.py` — shared no-reset board serial Console (all tracks; `--port` / `$CTF_PORT`)
- `solvers/README.md` — solver setup: venv from /usr/bin/python3, port option, organizer-only (spoilers)
- `README.md` — short visual overview: banner, quick start, tracks, modes, hardware, toolbox pointers, organizer links
- `docs/toolbox.md` — full per-track tool table + install hints (moved from README)
- `docs/development.md` — build from source, release script, host tests, dev options (Wi-Fi password warning), organizer notes
- `docs/img/` — README images, `<name>-light.png` / `<name>-dark.png` at 2x (`console.png` single, always dark)
- `docs/img/src/` — one self-contained HTML source per image (`?theme=dark` for dark); `make_i2c.py` generates `i2c.html` from a sigrok capture (`.sr` not in repo)
- `scripts/render-images.sh` — renders `docs/img/src/*.html` to `docs/img/*.png` with headless Chrome
- `docs/players/` — spoiler-free player guides: index + one per track
- `scripts/release.sh` — clean release build, dev-option guard, merged .bin → dist/, ESP Web Tools manifest, web/flasher/dist-site/ (flasher at root + player app in app/, cross-links rewritten)
- `web/flasher/` — flasher landing page (esp-web-tools 10.4.0) + manifest; hero links to the player app
- `web/app/` — player app (static, no build): Web Serial client, demo board (`?demo`), xterm.js 6.0.0 console; README for local serving
- `web/app/index.html`, `web/app/app.css` — Connect + Play screens per `docs/design/player-app/`, design tokens
- `web/app/js/main.js` — app state, rendering, hints/flag/mode actions, polling, primer view
- `web/app/js/link.js` — STX/ETX frame parser + one-at-a-time SOH request queue (SPEC "Machine channel")
- `web/app/js/serial.js` — Web Serial transport (115200, DTR+RTS asserted, read loop)
- `web/app/js/demo.js` — in-memory fake board speaking the same protocol (placeholder hints, flag body DEMO00000000)
- `web/app/js/terminal.js` — console drawer (xterm.js + fit addon, plain-text fallback)
- `web/app/js/markdown.js` — tiny escaping Markdown renderer for primers
- `web/app/content/challenges.json` — generated briefs + tools per challenge (do not edit; see build-app-content.py)
- `web/app/content/primers/<track>.md` — per-track primers (ble, btc, web, serial, hw, re, crypto)
- `scripts/build-app-content.py` — docs/players/*.md → web/app/content/challenges.json (`--check` for staleness)
- `LICENSE` — MIT
- `docs/design/player-app/` — approved player-app mockups (Design Component HTML), v0.2.0 reference
