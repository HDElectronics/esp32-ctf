# Player app

A static web app for playing the CTF in the browser: it talks to the board
over Web Serial (desktop Chrome or Edge), shows the challenges, your points
and hints, checks flags on the board and has the serial console built in.
No build step: HTML, CSS and ES modules. xterm.js 6.0.0 and its fit addon
0.11.0 load from jsDelivr (pinned, with SRI in the import map).

## Run it locally

```sh
python3 -m http.server -d web 8000
```

Then open <http://localhost:8000/app/>. Web Serial only works on a secure
page; `localhost` counts, a LAN IP over plain HTTP does not.

- Demo board, no hardware needed: <http://localhost:8000/app/?demo>
- Machine-channel traffic in the browser console: add `?debug`

The demo board is a fake ESP32 inside the page. Its hints are placeholders and
its only accepted flag body is `DEMO00000000` (solves the selected challenge).

Other query parameters, handy for screenshots: `sel=BLE-03`, `tab=web`
(or `all`), `console=1`, `primer=ble`, `screen=connect` (with `?demo`) and
`fallback` (the no-Web-Serial Connect screen).

## Files

- `index.html`, `app.css`: both screens (Connect, Play), design tokens
- `js/main.js`: state, rendering, actions
- `js/link.js`: frame parser and one-at-a-time request queue (SPEC "Machine channel")
- `js/serial.js`: Web Serial transport; `js/demo.js`: demo board
- `js/terminal.js`: console drawer; `js/markdown.js`: primer renderer
- `content/challenges.json`: briefs and tools, generated by
  `scripts/build-app-content.py` from `docs/players/*.md` (do not edit by hand)
- `content/primers/<track>.md`: one short primer per track

`scripts/release.sh` copies this folder into the hosted site as `app/`, next
to the flasher page.
